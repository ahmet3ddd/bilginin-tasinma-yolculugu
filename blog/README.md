# blog

Bu klasör çalışmanın kendisi değildir. Blogda yayımlanan tanıtım
metinlerinin ve kapak görselinin arşiv kopyasıdır.

- `01-tanitim-yazisi-TR.md` — blogda yayımlanan tanıtım yazısı
- `02-kisa-giris-TR.md` / `-EN.md` — kısa giriş yazısı
- `blog-kapak.png` — 1000×1000 kapak görseli

Çalışmanın kendisi kök dizindeki `index.html` dosyasıdır.
